# Максим Лебедев · Team Lead .NET

Статическое портфолио на HTML, CSS и JavaScript. Исходники сайта лежат в `docs/`. Устанавливать зависимости и собирать проект не нужно.

## Запуск в VS Code

1. Откройте папку проекта в VS Code.
2. При установленном Node.js выполните из корня проекта:

   ```powershell
   node scripts/serve.cjs
   ```

   Также доступна задача VS Code **Portfolio: localhost** (Terminal → Run Task).

   Альтернативный запуск через Python:

   Windows:

   ```powershell
   py -m http.server 8000 --bind 127.0.0.1 --directory docs
   ```

   macOS/Linux:

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
   ```

3. Откройте [http://localhost:8000](http://localhost:8000). Остановить сервер можно через Ctrl+C.

## Редактирование

Текст, ссылки и кейсы находятся в `docs/index.html`, оформление - в `docs/styles.css`. Чтобы обновить резюме, замените `docs/assets/resume.pdf`.

Основные разделы: «О себе», «Матрица компетенций», «Кейсы», «Моя ценность». История работы раскрывается внутри «О себе». Ссылки из матрицы открывают соответствующий кейс; прямые ссылки вида `/#case-qase` также поддерживаются. На мобильных экранах строки матрицы отображаются карточками.

Компетенции подкреплены кейсами из опыта владельца портфолио. По согласованию пункт референса «Управление подрядчиками» заменен на «Межкомандную координацию»: работа велась с другой внутренней командой компании. Подтверждены Claude, ChatGPT, DeepSeek и Cursor: обучение manual QA написанию автотестов, написание автотестов и подготовка тестовых сценариев. Для разработки в проекте использовали Cursor, думающие модели и агентскую разработку; подготовили Markdown-файлы и контекст проекта. Сокращение времени регрессионных прогонов на 56% относится ко всему комплексу улучшений тестирования.

Переключатель EN/RU переводит всю страницу, включая кейсы, мобильные подписи, метаданные и названия элементов для скринридеров. Выбор языка сохраняется в браузере. Русский текст хранится в `docs/index.html`, переводы - в словаре `docs/i18n.js`; при изменении русского текста обновите соответствующий ключ словаря. PDF скачивается в исходном виде на русском языке.

## GitHub Pages

Когда будете готовы опубликовать портфолио, загрузите проект в свой репозиторий GitHub. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/docs**, затем нажмите **Save**. GitHub покажет адрес сайта в настройках Pages после публикации. Сверьте контакты и содержимое PDF перед публикацией.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
